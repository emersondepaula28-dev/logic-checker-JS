# Logic Checker JS

Este é um aplicativo simples de verificação de lógica desenvolvido em JavaScript durante o Workshop do **freeCodeCamp**.

## Conceitos Praticados

* Variáveis e Tipos de Dados (`const`, `let`)
* Operadores Booleanos (`true`, `false`)
* Estruturas Condicionais (`if`, `else`)
* Manipulação e Depuração de Console

## Tecnologias
* JavaScript (ES6+)
